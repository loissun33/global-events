## 📝 events.csv 字段说明

| 字段 | 说明 |
|------|------|
| 日期收录 | 数据入库日期（YYYY-MM-DD） |
| 活动名称 | 官方名称 |
| 类型 | Demo Day / Hackathon / 大会及边会 / Meetup |
| 地区 | 中国大陆 / 港澳台 / 东南亚 / 北美 / 欧洲 / 日韩 / 澳新 / 中东 / 线上 |
| 城市 | 活动城市 |
| 开始日期 | YYYY-MM-DD |
| 结束日期 | YYYY-MM-DD |
| 报名截止 | YYYY-MM-DD（有则填写） |
| 官方链接 | 活动官方页面 |
| 来源 | 信息来源平台 |

## 🔔 如何使用

- **Watch** 这个仓库 → 每次日报推送都会收到通知
- 直接下载 `events.csv` → 用 Excel / Notion / 飞书多维表格导入
- 查看 `reports/` 目录 → 阅读日报 / 周报 / 月报
